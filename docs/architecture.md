
### Architecture Principles

| Principle | Implementation |
|-----------|----------------|
| **Single Responsibility** | Each module has one clear purpose |
| **Separation of Concerns** | CSS, HTML, and JavaScript are properly separated |
| **Modularity** | ES Modules for clean dependency management |
| **State Management** | Centralized state with Observer pattern |
| **Pure Functions** | Utilities are side-effect free and testable |
| **Progressive Enhancement** | Works without JavaScript, enhanced with it |
